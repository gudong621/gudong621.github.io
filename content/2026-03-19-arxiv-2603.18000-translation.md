## 摘要 (Abstract)

构建基于大语言模型 (LLM) 的智能体已变得日益重要。近期关于 LLM 智能体自进化的研究工作主要将成功经验记录为文本提示 (prompts) 或反思 (reflections)，这种方式无法可靠地保证在复杂场景中高效地重新执行任务。

我们提出了 **AgentFactory**，一种全新的自进化范式：它将成功的任务解决方案保存为**可执行的子代理代码**，而非文本经验。关键在于，这些子代理会根据执行反馈持续优化，随着遇到更多任务而变得日益鲁棒和高效。

保存的子代理是带有标准化文档的纯 Python 代码，可在任何支持 Python 的系统中移植。我们证明，AgentFactory 能够实现连续的能力累积：其可执行子代理库随时间增长并改进，逐步减少完成类似任务所需的努力，且无需人工干预。

## 核心贡献 (Key Contributions)

### 1. 问题洞察

现有自进化方法的根本缺陷：
- 依赖文本形式的经验记录（提示词、反思）
- 文本经验缺乏可执行性和可验证性
- 在复杂场景中无法保证任务的高效重执行

### 2. 创新方案

**AgentFactory 范式**：
- **可执行子代理**：将成功解决方案保存为 Python 代码
- **标准化文档**：确保代码的可读性和可移植性
- **反馈驱动优化**：基于执行结果持续改进子代理质量

### 3. 核心优势

- **能力累积**：子代理库随时间不断增长和进化
- **效率提升**：类似任务的执行成本逐渐降低
- **自动化**：无需人工干预的持续改进循环
- **可移植性**：纯 Python 代码可在任意系统运行

## 技术要点 (Technical Highlights)

### 子代理生命周期

```
任务执行 → 成功 → 代码提取 → 文档生成 → 存入子代理库
                              ↓
                        遇到类似任务
                              ↓
                        检索子代理 → 执行 → 反馈
                              ↓
                        优化子代理代码
```

### 关键设计原则

1. **代码优于文本**：可执行代码比文本提示更精确、更可靠
2. **持续进化**：子代理不是一成不变的，而是随使用不断优化
3. **标准化接口**：统一的文档规范确保子代理的互操作性
4. **反馈闭环**：执行结果直接驱动代码优化
